# CodeSense

AI-powered code review and debugging platform built with Java and Spring Boot.

## Vision

CodeSense analyzes source code, pull requests, and application errors to identify bugs, code-quality issues, root causes, and actionable fixes.

## Project Goals

- AI-assisted code reviews
- Static analysis + AI analysis
- Stack-trace debugging
- GitHub pull request integration
- Asynchronous analysis with Kafka
- Secure, production-ready REST APIs
- Dockerized local development
- Automated testing and CI/CD
- Observability and operational readiness

## Planned Technology Stack

- Java 21
- Spring Boot
- Spring Security
- PostgreSQL
- Redis
- Apache Kafka
- Docker
- GitHub API
- OpenAPI / Swagger
- JUnit 5 / Testcontainers
