# CodeSense Documentation

This directory contains the engineering documentation for CodeSense.

- `architecture.md` — high-level architecture and service boundaries
- `api-design.md` — REST API contracts

- `deployment.md` — local, staging, and production deployment

Documentation will be added alongside implementation rather than after the fact.
